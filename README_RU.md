# Valuta Cash v4

Что добавлено:

- Банки: MAIB, Victoriabank, Moldindconbank, OTP Bank, Eximbank, ProCredit Bank, FinComBank, Energbank, EuroCreditBank.
- Отдельный выбор банка.
- Покупка/продажа валюты.
- Любые пары валют, если источник имеет обе валюты.
- Полностью свободный «Мой курс»: можно поставить любой курс между любыми валютами.
- Сохранение своих курсов в телефоне/браузере.
- Быстрые значения курса.
- Кэш последних онлайн-курсов.
- Автообновление через Cloudflare Worker каждые 10 минут после настройки API_URL.

## Как опубликовать

1. Загрузите файлы в GitHub Pages.
2. Создайте Cloudflare Worker из `worker.js`.
3. После публикации Worker получите HTTPS-адрес вида `https://...workers.dev`.
4. Откройте `app.js` и замените:
   `const API_URL = "";`
   на адрес Worker.
5. Сохраните `app.js` и загрузите его в GitHub.

Worker получает таблицы банков через euro.md. На странице euro.md указано, что данные берутся с официальных сайтов банков и могут отличаться по отделениям.

Для точности перед обменом всегда проверяйте курс конкретного отделения.
